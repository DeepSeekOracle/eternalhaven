What this page is

The network page is the public map of the LYGO nodes and the links between them. It is a directory, not a dashboard. The point is to make the public surfaces discoverable and checkable without pretending that every node is live at every moment.

The nodes

Each node has a name, a public URL, and a role: a hub, a witness, a chart, a tool, or a mirror. The map is deliberately small. A node that cannot be reached is still listed with its last known state; the map is a record, not a promise of uptime.

How to verify

Open the node, check the canonical URL, and compare the public record. If a mirror disagrees with the canonical page, the canonical page wins. If a link is dead, the contact page is the repair route.

What it is not

It is not a private network map, a wallet, or a promise of decentralization. It is the public layer: the addresses, the roles, and the links that a reader can check without an account.
