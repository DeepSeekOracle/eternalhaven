A house, not a kiosk

Feeds are weather. Sites are houses. I would rather own a small messy hallway than rent a clean cage. This homepage is for sitting: a few honest doors, writing that could only have come from this desk, and no requirement that you perform a like before you lurk. The dense systems map still exists — the hub — one click away for people who already live here. Guests get a chair first.

I am Justin Helmer. I also publish music as Excavationpro. Steward work sometimes uses the name Lightfather. You do not need those names to read a chapter. You can learn them on the about page if you want a second tour.

What is actually here, in plain terms: five novels in one continuous saga, a shelf of essays about craft and small systems, a catalog of original music that is free to hear, and a handful of browser rooms that do one job each. What is not here: a newsletter wall, a login, an autoplay player, or a page that exists only to point at another page. Every door on this site opens onto writing I wrote for this domain, and the ones that used to be bare redirects now explain themselves.

What this house is

Eternal Haven is the library side of the workshop: books, essays, games, and the public rooms that connect them. It is not a storefront and not a second music player. The books live here, the essays explain the work, and the games directory points to the upgraded arcade at chatagent.ca.

The site is organized by what you want to do. If you want to read, start with the books or the essay index. If you want to play, the games page sends you to the live arcade. If you want the music, the player is on asiancoastline.com. If you want the wider tools, the LYGO hub and the tools hub are the map.

The rooms

The books page holds the long-form work. The essay index holds the shorter arguments about craft, maps, music, and public systems. The LYGO hub links the protocol and agent material. The witness, Star Chart, and network pages are the public lattice surfaces. Each one has a job; none of them is a placeholder.

How to use the library

Start with the thing you came for, not with the whole site. A reader can finish one essay and follow its links; a builder can open the hub and pick a tool; a listener can go straight to the player. The search engines can index the pages, but the human path is one room at a time.

If a page is missing or a link is broken, the contact page is the repair route. The library is maintained, not frozen.
