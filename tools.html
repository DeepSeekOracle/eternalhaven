Tools

The tools room

Free, no account, no upload where it can be avoided. What each tool does, what it does not do, and where the honest limits are.

JH
Justin Helmer
Guide · updated 6 November 2026 · about an eight-minute read

Every tool in this room follows one rule: the tool is the product, not the funnel. No account, no newsletter wall, no "sign in to save". Where something needs a key, the page says so before you click. Where a tool could upload your file, it works in the browser instead.

In this house

The ASCII art studio. /lygo-ascii-art.html turns a photo into letters, numbers, and symbols. It runs entirely in your browser, which means the picture you drop on it never leaves your machine. Density, character set, and width are adjustable. It is a toy with a real use: a poster, a terminal banner, a portrait that survives being pasted into a plain-text file.

The Star Chart. /starchart/ is a live view of anchored seals: what has been recorded, when, and under which root. It is a public ledger page, so treat it as reference: a number you can check, not a claim you have to believe. The glossary defines Merkle root if the vocabulary gets thick.

The witness. /witness/ watches public feeds — weather, seismic, orbital — and shows what they say without editorial. The point is not prophecy. The point is a page that will tell you the feed is down instead of showing you a stale number with a confident font.

God's Eye. /godseye/ is the same idea on a globe. One map instead of nine tabs. It is named with a deliberate amount of irony; a globe is not an authority, and the page says so.

The lattice kernel. /lattice/ is the workshop's self-audit room: a local monitor that reports rather than acts. It exists because a system that cannot describe its own state is a system you have to trust blindly, and I would rather not.

Next door, on the other domains

The workshop is spread across several domains because each one was built for one job. The tools that are not on this domain:

  • BPMfinder tools — tap tempo, BPM detection, and the small utilities around them. This is the tool hub for the music side.
  • Asian Coastline — the free listen player for the Excavationpro catalog. No account, no preview wall.
  • The image studio — the workshop's picture tool, with provider health shown honestly instead of a spinner and a promise.
  • The arcade — the browser games that used to live on this domain. The games page here explains the move.

What these tools are not

They are not products with a roadmap meeting. None of them stores your work on a server, sells your inputs, or asks for an email. That is not a marketing position; it is a maintenance decision. A tool that keeps no data is a tool I can leave running for years without a privacy incident, a breach notice, or a compliance page written by a lawyer at midnight.

The flip side is scope. These are small tools built by one person. They break when a browser changes something, and the repair is not instant. If one is broken, tell me; the contact page is the bug tracker.

Why give them away

Because a tool that costs nothing to run and asks nothing of you is the closest thing to a gift the web still allows. The essays explain the economics at length; the short version is that the books pay for the hosting and the tools pay for themselves in usefulness. No advertisement runs inside a tool screen in this house. That is deliberate, and it is also why the tools page you are reading is the only place an ad could sit without ruining the thing it sits on — so it does not.

How to suggest a tool

Ask for something small and specific: "a page that takes a CSV and prints the column widths" is a request I can honour. "An AI platform" is not. The workshop's rule is that a tool ships when it can be described in one sentence and verified in one sitting. If you want the longer argument, Systems that break early is the essay that set the policy.
