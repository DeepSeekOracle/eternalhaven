What is this?

      

        ASCII art (also text art or type art) maps image brightness to a ramp of characters.
        Darker cells get denser glyphs (@#%█); lighter cells get sparse ones (.:· ).
        Optional color samples the original pixels so the text still “looks like” the photo.
      

      
    
        
  • Use cases: posters, terminal wallpapers, album art previews, lattice memes, README banners.
    • 
        
  • Best sources: high-contrast portraits, logos, and simple scenes.
    • 
        
  • Export: plain text for editors; PNG for sharing with color preserved.
