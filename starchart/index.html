    What this is

    The Haven Star Chart feed is CANON: append-only, hash-chained, published on GitHub Pages. GitHub Pages cannot accept POST. Hugging Face can. So live writes from bots land on the dataset as star-monitor.json (always) and pending/ proposals (consent). A steward still runs gate → ingest → rebuild before the Pages chain grows.

    Autonomy

    • Autonomous: re-GET the public feed, verify prev_hash links, refresh the HF monitor file.
    • Consent: queue a proposal JSON to the dataset or open a GitHub issue.
    • Not autonomous: forging entry_hash, silent git push, steward ingest.
